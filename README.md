**🛡️ DeepShield** — *compression-robust deepfake detection*
Multi-scale adaptive CNN extending FaceForensics++ with Grad-CAM. 96.30% acc · 0.9903 AUC, +15.30 pp over baseline on the hardest compression setting.
`PyTorch` · `Grad-CAM` · `timm` · `FF++` — [Repo](https://github.com/monum-hashmi/msafe-gc-deepfake-detection)

**🚗 Suspicious Vehicle & Person Tracker** — *real-time multi-object tracking*

**💬 Toxic Comment Classifier** — *NLP with SHAP explainability*
